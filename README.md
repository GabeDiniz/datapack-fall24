# Description
Our Fall-2024 server datapack (1.21.1)! This datapack has custom commands and has numerous new advancements. It allows you to easily turn on UHC mode and automatically swaps between number of deaths and hearts in the dropdown scoreboard. 

# For development
```
Version: 1.21.1
Datapack Format: 48
```

# Usage
```
/function uhc:on    # turn on UHC mode
/function tp:sethome   # sets home
/function tp:home   # teleports user home
```
